# Provider cost is the only priced dollar amount; subscriptions are included

Rika does not estimate model attempt cost from the models.dev snapshot or any other local rate table. Tokens come from provider usage reports. Dollars come only from a provider-reported USD amount on the model attempt. An absent provider cost on a metered attempt stays unpriced; a guessed cost is not.

An attempt on an OpenAI account route is part of the attached Codex subscription, so its usage is counted as included rather than unpriced or priced. The Cost row states `Included in subscription` instead of `$0.00` or an invented dollar amount.
