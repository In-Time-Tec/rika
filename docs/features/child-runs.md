# Child Runs

A Child Run is a durable child Execution with narrowed instructions and capabilities. Each child has a deterministic identity, isolated durable Session, pinned profile, route, static capabilities, and output contract; conversational children also carry a compaction policy.

A cell selects only children declared by the active parent manifest. Root declares Oracle, Librarian, Painter, ReadThread, Review, Surgeon, and Task, and a cell may spawn any declared child. Task may select Oracle, Librarian, Painter, ReadThread, Surgeon, or another Task until Baton's pinned delegation depth budget is exhausted; all other children are leaves. The ambient operation identity plus a host ordinal owns idempotent admission, and cancellation is durable across the exact child closure. A parent may inspect any number of its direct children in one request; Rika resolves their ownership from one durable tree view rather than rescanning that tree once per child.

One top-level Execution may admit at most six model-authored Child Runs through `rika.agents.spawn`. The limit is cumulative across the whole execution tree: recursive Task descendants and terminal children count, while durable replay resolves its recorded receipt before re-entering admission and does not count again; the independent title Execution and product-authored Review fan-out also do not count. A new top-level Execution receives a new allowance.
