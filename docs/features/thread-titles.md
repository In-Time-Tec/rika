# Automatic Thread titles

A new interactive Thread starts with a temporary title derived from its first prompt and applies it to the terminal as soon as the Thread is activated for that submission. Alongside the first Turn, Rika starts a deterministic internal Execution on the pinned title route at low effort, stores up to eighty characters from its concise result, and updates the open terminal and Thread summaries. Selecting another Thread applies its current title to the terminal.

The title Execution has an isolated durable Session with no parent mailbox, tools, delegation, or compaction, so its settlement cannot become a conversational model request. Rika resumes or replays it after restart, and its model usage contributes to the first Turn, Thread, and global cost totals. An unavailable route, failed request, or empty response leaves the existing title in place.
