# Mode selection

Users choose one of the `low`, `medium`, `high`, or `ultra` behavior modes from the mode selector. Clicking the footer mode label, using the mode shortcut, or choosing the command-palette action opens it. The selector starts on the active mode, wraps during keyboard navigation, previews the hovered mode's Agent and Oracle routes and description, and applies a committed selection to later submissions. Escape closes it without changing the mode.

The selector accent follows the hovered mode. A committed mode retypes the footer label and wipes the context meter into the new mode color. Each mode supplies its configured reasoning effort and model route. Fast mode is a separate toggle; the terminal does not offer a direct reasoning-effort override.
