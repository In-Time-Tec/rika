# Specialist agents

The main agent can run durable Title, Task, Oracle, Librarian, Painter, Surgeon, and ReadThread children through product-named tools. Each tool suspends on Baton's durable child join and returns the child's terminal result, so no product child ledger, polling tool, or parsed child identifier is involved. A suspended parent and child resume after restart, duplicate tool admission resolves to the same child, and a child that outlives its parent Execution is cancelled. Task investigates the workspace and changes it only when assigned. Oracle is a read-only advisor for high-level planning, architecture tradeoffs, difficult debugging analysis, and review of focused, already-gathered evidence, not primary codebase exploration. Librarian handles substantive external documentation, repository, and codebase research, including current API or library behavior, public implementation examples, compatibility and release evidence, and cited source verification. Painter handles focused visual analysis. Surgeon reproduces and isolates a specific defect and may add temporary instrumentation. ReadThread searches current or historical local Thread transcripts and returns a grounded free-form answer.

Task and Surgeon use the selected mode's main route. Oracle, Librarian, Painter, and ReadThread use its Oracle route. Root has the seven declared child selections. Task has only Oracle, Librarian, Painter, ReadThread, and Surgeon; it never receives Task recursively. Every other child is a leaf. Child Runs use the parent manifest's pinned selection, route, and capability snapshot; cancellation and failure return Baton's explicit terminal child result rather than widening access.
