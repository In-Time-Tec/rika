# Specialist agents

The main agent runs durable Task, Oracle, Librarian, Painter, Review, Surgeon, and ReadThread children through TenetKit's model-facing child tools. `run_child` admits one child and suspends the parent until its durable result exists. `run_child_group` atomically admits one exact independent group and suspends the parent until every member settles. Settlement resumes the same parent Run without a synthetic user Turn, polling, or a Rika-owned inbox. A suspended parent and child resume after restart, and a child that outlives its parent Execution is cancelled. Title is admitted by Rika and cannot delegate. Task investigates the workspace and changes it only when assigned. Oracle is a read-only advisor for planning, architecture tradeoffs, difficult debugging, and focused review. Librarian handles substantive external documentation, repository, and codebase research. Painter handles focused visual analysis. Surgeon reproduces and isolates a specific defect. ReadThread searches current or historical local Thread transcripts.

Task and Surgeon use the selected mode's main route. Oracle, Librarian, Painter, and ReadThread use its Oracle route. Every recursively capable profile has the seven declared child selections until `subagents.maxDepth` is reached. Child Runs use the parent manifest's pinned selection, route, capability snapshot, and per-parent `subagents.maxSubagents` active capacity; cancellation and failure return TenetKit's explicit terminal child result rather than widening access.
