# Specialist agents

The main agent runs durable Task, Oracle, Librarian, Painter, Review, Surgeon, and ReadThread children from a cell through `rika.agents`. A spawn is admitted under a key derived from the ambient operation identity and host ordinal, so replay resolves to the same child. `rika.agents.inspect` reports current status and outcome; a running child also carries its last durable activity time and a bounded latest-step preview. `inspectAll` is an immediate snapshot, never a wait. Every terminal child writes one typed `ChildSettlement` to the parent's durable `rika.agents.inbox`; the notification carries success, failure, or cancellation and a result bounded by Baton to 16 KiB. `inbox({ afterSequence, limit })` pages settlements across cells without polling and continues to return them after their mailbox envelopes have been delivered. An oversized successful result is stored in Rika artifacts, and the settlement supplies the artifact ID and bounded slicing instructions instead of exposing Baton's internal snapshot API. `cancel` cancels a child. A suspended parent and child resume after restart, and a child that outlives its parent Execution is cancelled. Title is admitted by Rika, not from a cell. Task investigates the workspace and changes it only when assigned. Oracle is a read-only advisor for planning, architecture tradeoffs, difficult debugging, and focused review. Librarian handles substantive external documentation, repository, and codebase research. Painter handles focused visual analysis. Surgeon reproduces and isolates a specific defect. ReadThread searches current or historical local Thread transcripts.

Task and Surgeon use the selected mode's main route. Oracle, Librarian, Painter, and ReadThread use its Oracle route. Root has the seven declared child selections. Task has Oracle, Librarian, Painter, ReadThread, Surgeon, and Task selections, so it may delegate recursively until Baton's pinned depth budget is exhausted. Every other child is a leaf. Child Runs use the parent manifest's pinned selection, route, and capability snapshot; cancellation and failure return Baton's explicit terminal child result rather than widening access.
