# Queued Turn controls

Input submitted while a Turn is active appears in a compact queue joined to the composer. Up enters the queue from newest toward oldest; Down moves toward newer items and then returns to the composer. Escape leaves queue navigation.

Enter while a Turn is active admits the composer text as a Pending Turn. Enter on a selected row withdraws that exact item and steers it into the active Execution. The selected row changes to `steering:` immediately and remains visible through durable withdrawal and Generalist acceptance until consumption puts the text in the transcript; a definitive rejection restores the ordinary queued row. Backspace dequeues a selected row and Ctrl+E loads it for editing. Enter saves an edit in its existing FIFO position and Escape cancels it. Queue controls act only on visible selected rows, and queued prompts remain outside the transcript until they are steered into the active Turn or promoted as their own Turn.

Steering journals the selected Pending Turn and request identity together in a durable admission outbox, atomically withdrawing the source from queue reads, edits, removals, and claims. An unknown Generalist outcome is retried with the same request identity after interruption. Generalist acceptance completes the queue handoff immediately; a definitive rejection restores the same source row at its original position. Repeated or stale controls cannot create a second admission for a withdrawn source.
